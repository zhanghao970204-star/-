# 每日返水/救济金（旧版）

## 入口与流程

- 旧 Bonus 页“游戏福利”卡跳转 `/cashBack`。
- 页面加载 `GetPromoDailyRelief`，展示当期可领取金额 `reliefAmount`、领取状态 `promoStatus` 与规则表 `ruleList`。
- 仅当 `promoStatus === 'not_receive'` 时可点击领取，调用 `ReceivePromoReliefAmount`；成功后重新加载。

## 规则来源

`ruleList` 为服务端返回的 JSON 字符串，前端解析后显示最低金额与比例。每日额度、计算口径和资格由后端决定。

## 相关实现

- 页面：`src/views/details/bonus/cashBack.vue`
- 接口：`/promo/getPromoDailyRelief`、`/promo/receivePromoReliefAmount`

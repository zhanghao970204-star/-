# 宝箱

## 入口与可见性

- 活动中心第三张横幅及 App 右侧全局悬浮按钮均打开同一个 `TreasureBoxPopup`。
- 登录后调用 `TreasureBoxInit`；只有响应中 `visible !== 0` 才展示。活动中心未登录时点击会先要求登录。

## 页面能力

- 弹窗展示宝箱价格、总价值、奖励列表和倒计时。
- 宝箱支付完成/弹窗关闭后会重新检查状态，因此入口与内容会随服务端状态变化。
- 旧的 `/firstDepositGift` 页面也使用此初始化接口，但活动中心当前使用共享弹窗，而不是该独立页面。

## 服务端决定的内容

前端读取 `price`、`totalValue`、`rewards`、`countdownSeconds` 与 `visible`。当 `totalValue` 缺失时，前端暂以 `price` 作为展示值；这只是容错，不代表奖励规则。

## 相关实现

- 弹窗：`src/components/TreasureBoxPopup.vue`
- 入口：`src/App.vue`、`src/views/layout/activity.vue`
- 独立旧页面：`src/views/details/activity/firstDepositGift.vue`
- 接口：`/promo/treasureBoxInit`

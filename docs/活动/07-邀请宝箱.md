# 邀请宝箱（旧版）

## 入口

旧 Bonus 页的“邀请好友”卡跳转 `/referFriend`。需要登录后才初始化用户资料和宝箱进度。

## 用户流程

1. 初始化调用 `TreasureReceiveInit`，获取当前有效邀请数 `currentCount`、已领取层级 `treasureLevel` 等状态。
2. 页面按每档所需邀请人数显示未达成、可领取、已领取三种宝箱状态。
3. 达到条件且高于已领层级时点击宝箱，调用 `ReceiveTreasure`；成功后重新拉取进度。
4. 页面还展示邀请码、分享链接和二维码，以便邀请新用户。

## 注意

宝箱档位人数、有效邀请定义、奖励金额与是否可领取均不是前端配置，应以 `treasureReceiveInit` 的返回和运营规则为准。

## 相关实现

- 页面：`src/views/details/bonus/referFriend.vue`
- 接口：`/promo/treasureReceiveInit`、`/promo/receiveTreasure`

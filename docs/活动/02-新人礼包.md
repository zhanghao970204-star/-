# 新人礼包（首充礼包）

## 入口与可见性

- 活动中心“Welcome Bonus”卡片进入 `/newbieGift`。
- App 会在登录后检查并显示全局首充悬浮入口及弹窗。
- 活动中心通过 `NewPlayerGiftPackInit` 的 `content.visible === 1` 决定是否展示卡片。

## 用户流程

1. 页面初始化获取礼包状态、购买状态、奖励及倒计时。
2. 页面将服务端第 1～3 天的状态展示为可领取、已领取或锁定。
3. 满足条件后，按天调用 `ReceiveNewPlayerGiftPack({ dayIndex })` 领取。
4. 首充/购买相关的支付动作由 `GiftPaySheet` 和支付工具处理；领取成功后刷新活动数据。

## 服务端决定的内容

前端消费 `purchased`、可见性、奖励/领取结果和倒计时等数据。前端的三日卡片是展示结构，具体金额、资格与支付条件应以接口响应为准。

## 相关实现

- 页面：`src/views/details/activity/newbieGift.vue`
- 全局弹窗：`src/components/FirstRechargePopup.vue`
- 接口：`/promo/newPlayerGiftPackInit`、`/promo/receiveNewPlayerGiftPack`

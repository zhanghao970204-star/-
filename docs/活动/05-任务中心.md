# 任务中心（新手、每日、每周）

## 入口

活动中心“Weekly Missions”列表项进入 `/weeklyMissions`。虽然入口名为周任务，页面实际含“新手 / 每日 / 每周”三类任务。

## 用户流程

1. 首先调用 `TaskCenterNewbieInit` 获取新手任务和 `newbieCompleted`。
2. 仅当新手任务完成后，再并行请求 `TaskCenterDailyInit` 与 `TaskCenterWeeklyInit`。
3. 每类任务展示进度、积分、任务奖励与里程碑奖励。
4. 进行中的任务会按接口 `actionUrl` 跳转；未提供时，内置映射会跳转邀请、充值、银行卡或首页投注入口。
5. 可领取的任务调用 `ClaimTaskReward({ category, taskCode })`；达标里程碑调用 `ClaimProgressReward({ category, threshold })`。

## 服务端决定的内容

任务名称、描述、图标、进度文本、状态、奖励、积分、里程碑阈值和重置时间均来自接口。前端仅提供状态转换与展示。

## 相关实现

- 页面：`src/views/details/activity/weeklyMissions.vue`
- 接口：`/promo/taskCenterNewbieInit`、`/promo/taskCenterDailyInit`、`/promo/taskCenterWeeklyInit`、`/promo/claimTaskReward`、`/promo/claimProgressReward`

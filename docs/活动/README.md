## 共通说明

- 新版活动中心是 `/activity`，未登录点击大多数卡片会弹出登录；红包雨仅在已登录时请求可见性。
- 新版页面会通过 `reportPromoPanel` 上报进入/离开事件；它不影响领取逻辑。
- 奖励、参与资格、时间和次数均由接口响应决定。文档仅描述前端已实现的字段和交互，不将演示文案当作正式运营规则。
- `rewardHistory` 是每日签到的辅助查询页，不是独立活动：它复用 `GetSignDaily`，按日期筛选免费/付费签到奖励。

## 入口重复关系

- “新人礼包”在全局中命名为 `first_recharge`，实际使用 `newPlayerGiftPack` 接口，和 `/newbieGift` 是同一套活动。
- “幸运转盘”在旧 Bonus 页以弹窗展示，在新版活动中心使用 `/luckyReferral` 页面；两者都依赖幸运转盘相关接口。
- “红包雨”同时出现在新版活动中心与旧 Bonus 页，均跳转 `/redPacket`。

# 每日签到

## 入口与定位

- 活动中心首张横幅、首页登录后的签到弹窗均进入 `/dailyCheckIn`。
- 页面提供“奖励记录”入口 `/rewardHistory`，以及充值入口 `/rechargeCont`。

## 用户流程

1. 进入页面后调用 `GetSignDaily` 取得 `signList`。
2. 页面仅展示本月“今天前 3 天至月末”的日期；已错过、今日可签、未来锁定、已领取分别显示。
3. 今日可领取免费签到，调用 `SignDaily({ type: 0 })`。
4. 付费签到使用 `SignDaily({ type: 1 })`；只有当天 `paySignStatus === 1` 才可领取，否则提示当天充值并跳转充值页。
5. 领取成功后重新请求签到数据。

## 服务端决定的内容

`signList` 中每一天至少被前端使用：`date`、`freeSignReward`、`paySignReward`、`isFreeSign`、`isPaySign`、`paySignStatus`。奖励值、签到资格与付费解锁条件都不在前端固定。

## 相关实现

- 页面：`src/views/details/activity/dailyCheckIn.vue`
- 奖励记录：`src/views/details/activity/rewardHistory.vue`
- 接口：`/activity/getSignDaily`、`/activity/signDaily`

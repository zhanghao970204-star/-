# 团队返佣（旧版）

## 入口与流程

- 旧 Bonus 页“全局洗码/团队返佣”卡跳转 `/teamRebates`。
- 页面调用 `GetTeamRebateInit` 读取当前返佣信息并展示可领取状态。
- 用户点击领取后调用 `ReceiveTeamRebateAmount`，成功即重新拉取初始化数据；失败显示接口消息。

## 规则来源

返佣金额、结算周期、参与资格与领取状态都由 `GetTeamRebateInit` 决定，页面只读取 `content` 并渲染。

## 相关实现

- 页面：`src/views/details/bonus/teamRebates.vue`
- 接口：`/promo/getTeamRebateInit`、`/promo/receiveTeamRebateAmount`

# 红包雨

## 入口与资格

- 活动中心有限优惠卡和更多活动列表均跳转 `/redPacket`；旧 Bonus 页也指向同一路由。
- 页面要求登录；活动中心只在已登录时请求红包数据并显示“更多活动”入口。

## 用户流程

1. 打开页面请求 `RedPacket`，获得轮次标识、活动状态及倒计时等数据。
2. 前端按状态显示未达标、倒计时、进行中、已领取或已结束，并在倒计时结束后自动重新拉取。
3. 进行中的一轮中，用户点击落下的红包；达到本轮最大点击次数后，调用 `GetRedPacket({ roundKey })` 结算。
4. 结果页显示 `awardAmount`，可查询领取记录。记录接口采用 `pageIndex`/`pageSize` 分页，每页 20 条。

## 服务端决定的内容

可参与资格、轮次、点击上限、倒计时、奖励金额与领取状态均由服务端返回；前端只负责动画和状态编排。
